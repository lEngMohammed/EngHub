# EngHub

منصة تفاعلية من صفحة واحدة لمهندسي الحاسب والشبكات: مجتمع لمشاركة الأفكار والحلول، مع أدوات يومية جاهزة للاستخدام داخل المتصفح.

🔗 **الموقع المباشر:** https://lengmohammed.github.io/EngHub/
## المميزات

- **مجتمع المهندسين:** انشر فكرة أو حلاً برمجياً أو شبكياً، مع إعجابات وتعليقات.
- **حاسبة Subnet / CIDR:** تعرض Network ID وBroadcast والقناع وأول وآخر عنوان وعدد العناوين المتاحة فوراً.
- **حاسبة زمن نقل الملفات:** تحسب زمن النقل من حجم الملف وسرعة الاتصال.
- **مرجع المنافذ والبروتوكولات:** جدول قابل للبحث السريع (HTTP، HTTPS، SSH، DNS، FTP وغيرها).
- **طرفية محاكاة (Sandbox):** تجربة أوامر الشبكات وأكواد بايثون البسيطة بدون اتصال حقيقي.
- واجهة داكنة بطابع تقني، تدعم العربية (RTL)، وتعمل على الجوال والحاسب.

## التقنيات المستخدمة

- HTML5 و JavaScript (Vanilla)
- Tailwind CSS (عبر CDN)
- خط Cairo من Google Fonts

## التشغيل محلياً

لا يحتاج المشروع إلى تثبيت أي حزم:

1. حمّل الملف `index.html`.
2. افتحه في أي متصفح حديث (يلزم اتصال بالإنترنت لتحميل Tailwind والخط).

## النشر على GitHub Pages

1. افتح **Settings ← Pages**.
2. اختر Branch: `main` والمجلد `/ (root)` ثم احفظ.
3. بعد دقائق يصبح الموقع متاحاً على الرابط أعلاه.

## ملاحظات

- المشاركات والتعليقات تُحفظ في متصفح الزائر فقط (localStorage) في هذا الإصدار.
- الطرفية محاكاة تعليمية ولا تنفذ أوامر حقيقية.
- نتائج الحاسبات للمساعدة والتعلم، فتحقق منها قبل اعتمادها في بيئات الإنتاج.
